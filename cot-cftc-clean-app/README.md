# COT Sync

Site web de recherche COT basé sur les rapports officiels CFTC.

## Ce que fait le site

- Recherche d'actifs dans les listes CFTC courantes.
- Synchronisation avec la CFTC depuis le bouton `Synchroniser`.
- Affichage du positionnement, longs, shorts, spreads, open interest et biais.
- Bande passante automatique avec les actifs du rapport.

## Publication

Le projet est prêt pour être mis en ligne avec `render.yaml`.
Une fois publié, il suffit d'ouvrir l'URL du site et de cliquer sur `Synchroniser`.

## Dossier utile

Les fichiers importants sont :

- `server.js`
- `package.json`
- `public`
- `data`
- `render.yaml`
