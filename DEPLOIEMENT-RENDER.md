# Mettre COT Sync en ligne sur Render

Le dossier est prêt pour Render.

## Ce qu'il faut publier sur GitHub

Publie tout le dossier `Rapport COT v15 app`, avec :

- `cot-cftc-clean-app`
- `render.yaml`
- `.gitignore`
- `SITE-WEB.md`
- `DEPLOIEMENT-RENDER.md`

## Sur Render

1. Ouvre Render.
2. Clique sur `New`.
3. Choisis `Blueprint`.
4. Connecte ton dépôt GitHub.
5. Sélectionne le dépôt du projet.
6. Render lit automatiquement `render.yaml`.
7. Clique sur `Apply`.

Après quelques minutes, Render donne l'URL du site.

## Utilisation finale

Une fois le site publié :

1. Ouvre l'URL Render.
2. Clique sur `Synchroniser`.
3. Cherche un actif.

Tu n'auras plus besoin de lancer le CMD sur ton PC.
